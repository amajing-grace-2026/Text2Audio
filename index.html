Key hanya disimpan di browser Anda (localStorage), tidak pernah dikirim ke mana pun selain Google. Google memberi kuota gratis bulanan. Cara membuat API key →

  1. Buka console.cloud.google.com dan buat project baru.
  2. Aktifkan Cloud Text-to-Speech API (perlu akun billing, ada kuota gratis bulanan).
  3. Menu APIs & Services → Credentials → Create credentials → API key.
  4. Klik key tersebut → API restrictions: pilih hanya Cloud Text-to-Speech API. Website restrictions: isi alamat GitHub Pages Anda, misalnya https://namaanda.github.io/*.
  5. Salin key, tempel di atas, klik Simpan & Tes.
